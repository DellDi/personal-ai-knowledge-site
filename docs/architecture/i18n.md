# Internationalization

## Locales

- `zh-CN`
- `en`

## URL Strategy

Both locales use explicit prefixes:

- `/zh-CN/`
- `/en/`

Root `/` is a language entry page and does not serve the main homepage.

## Content Strategy

Content has `lang` and `translationKey`. Public queries filter by `lang`.

## SEO

Public detail pages generate canonical URLs and alternate links for available translations.
