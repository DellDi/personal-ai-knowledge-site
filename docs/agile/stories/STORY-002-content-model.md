# STORY-002: Content Model

## Background

All public content should be validated and queryable through Astro Content Collections.

## Scope

- podcast
- posts
- knowledge
- topics
- projects
- resources
- glossary
- timeline

## Acceptance

- [ ] Published content requires `lang`, `translationKey`, `slug`, `title`, `description`, `tags`, and `status`
- [ ] Draft content does not appear in public surfaces
- [ ] Each core collection has seed content
