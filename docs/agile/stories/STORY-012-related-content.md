# STORY-012：相关内容推荐

## 背景

详情页之间没有关联，读者看完一篇内容后没有继续阅读的路径。

## 范围

- 新增 `getRelatedEntries` 函数：按语言、标签重叠度、同集合加权计算
- 排除自身和同 translationKey 的翻译版本
- 新增 RelatedEntries 组件：所有详情页底部展示
- EntryLayout 通过 `after-content` slot 注入

## 验收标准

- [ ] 所有详情页底部展示相关内容（有匹配时）
- [ ] 不展示自身和翻译版本
- [ ] 同集合内容权重高于跨集合
- [ ] 标签重叠越多排名越靠前
