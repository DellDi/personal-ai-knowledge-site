# STORY-011：播客与知识库详情增强

## 背景

播客详情页只有音频和正文，缺少时间轴和资源链接。知识库详情页缺少上下篇导航，列表页缺少文档树侧边栏。

## 范围

- podcast schema 扩展 timeline / resources 字段
- 新增 PodcastTimeline 组件：结构化时间轴，点击跳转音频位置
- 新增 PodcastResources 组件：本期资源链接，含标签和备注
- 知识库 index 改为按 area 分组 + 文档树侧边栏（details/summary 可折叠）
- 新增 EntryNav 组件：同区域上下篇导航
- 知识库详情页注入 EntryNav

## 验收标准

- [ ] 播客详情页展示时间轴和资源组件
- [ ] 知识库列表页按区域分组，侧边栏树形导航可折叠
- [ ] 知识库详情页底部展示同区域上下篇
- [ ] 320px 移动端无横向滚动、无控件重叠
