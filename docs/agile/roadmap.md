# Roadmap

## Round 1: Platform Foundation

- Astro minimal app under `apps/web`
- pnpm workspace
- Content Collections for podcast, posts, knowledge, topics, projects, resources, glossary, timeline
- `/zh-CN` and `/en` routing
- Light and dark themes
- Home, list, detail, tag, search, RSS, podcast RSS, sitemap, 404, and admin shell routes
- Docker Compose production static deployment through Nginx
- AGENTS.md, project Skill, Agile Markdown, and architecture docs

## Round 2: Content Experience

- Podcast detail enhancements: timeline, transcript, resources, related content
- Knowledge base enhancements: document tree, mobile drawer, doc pager, ordered areas
- Topic aggregation across collections
- Pagefind filters by language, collection, and tag
- RelatedContent strategy by language, tag, topic, and collection
- Content map and tag index
- Article, PodcastEpisode, and Breadcrumb JSON-LD
- OG image strategy
- Release checklist
- Admin framework decision: `apps/admin`, external CMS, or Git-based CMS
- AI RAG export contract from Content Collections
