## 这个专题在讲什么

AI Agent 工程化是我过去一年投入最多的方向。这个专题把我在这个主题上的文章、播客和知识库文档串起来，按“入门 → 深入 → 排查”的顺序阅读，能形成相对完整的认知。

## 推荐阅读顺序

### 1. 先读文章：建立全局认知

[AI Agent 工程化实践：从套壳到可维护的系统](/zh-CN/posts/ai-agent-engineering) 是这个专题的入口。它梳理了四条主线：提示词治理、工具编排、上下文管理、评估闭环。读完它你会知道工程化到底在管什么。

### 2. 再听播客：理解决策取舍

[S01E01｜AI Agent 工程化对谈](/zh-CN/podcast/s01e01-ai-agent-engineering) 是文章的补充。文章只写结论，播客聊的是“为什么这么做”——很多取舍在文章里展开不了，放在播客里讲。

### 3. 最后查手册：落地排查

[AI Agent 排查手册](/zh-CN/knowledge/ai-agent-troubleshooting) 是可复用的工具书。当你的 Agent 出问题时，按故障分类逐项排查，每条都附了定位步骤和常见原因。

## 这个专题后续会补什么

- 工具编排的独立文档（读侧 / 写侧 / 检索侧分层细节）
- 评估闭环的用例集模板
- 上下文压缩的具体策略
