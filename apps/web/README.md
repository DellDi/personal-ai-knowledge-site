# Web App

Astro public site for the Personal AI Knowledge Site content platform.

## Commands

Run from the repository root:

```bash
pnpm -C apps/web dev
pnpm -C apps/web check
pnpm -C apps/web build
pnpm -C apps/web preview
```

## Key Features

- `zh-CN` and `en` route prefixes
- Astro Content Collections
- Editorial Brutalism design tokens
- Light, dark, and system theme preference
- Pagefind static search index after build
- RSS, podcast RSS, and sitemap
- Static admin reservation page at `/admin`
